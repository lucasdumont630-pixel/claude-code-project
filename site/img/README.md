# Fotos de la barbería

La web usa fotos de muestra (Unsplash) hasta que pongas las tuyas.
Guarda aquí tus fotos reales (las de Booksy o Instagram) con estos nombres
y cambia el `src` de cada `<img>` en `index.html` por `img/<nombre>.jpg`:

| Archivo        | Dónde sale                     |
|----------------|--------------------------------|
| hero.jpg       | Portada (vertical 4:5)         |
| corte-1..4.jpg | Galería de cortes              |
| barba-1..2.jpg | Galería, filtro "Barba"        |
| local-1..2.jpg | Galería, filtro "El local"     |
| club.jpg       | Sección "Por qué Club 13"      |

La edición (tono cálido, contraste, viñeta y grano) se aplica sola por CSS
a cualquier foto que pongas. Al pasar el ratón se ve la foto original.
