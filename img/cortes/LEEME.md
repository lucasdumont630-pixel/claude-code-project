# Fotos de cortes

Sube aquí tus fotos (JPG/WEBP, cuadradas o verticales 4:5, ~1200px).
Luego, en `index.html`, busca el array `CORTES` y pon el nombre del archivo en `foto`:

    { nombre: "Skin fade + texturizado", cat: "fade", foto: "img/cortes/skin-fade-1.jpg", ... }

Mientras `foto` esté vacío, la web dibuja una textura de pelo generada con el perfil de ese corte.
