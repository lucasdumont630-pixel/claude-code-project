# Danto · Authentic Italian Food

Web del restaurante Danto. Abre `index.html` en el navegador.

- `index.html` – estructura y contenido
- `styles.css` – estilos
- `script.js` – menú móvil, filtro del menú, galería y formulario de reservas

Las fotos vienen de Unsplash. Para usar fotos propias, sustituye las URLs `https://images.unsplash.com/...` en `index.html` por la ruta de tus imágenes (por ejemplo `images/pizza.jpg`).
