# La Argentina Estilista

Web de una página para la peluquería **La Argentina Estilista**. Todo va en un solo archivo (`index.html`) sin dependencias ni paso de compilación: ábrelo en el navegador o súbelo tal cual a cualquier hosting estático (Vercel, Netlify, GitHub Pages).

## Qué cambiar

Al final de `index.html`, en el bloque `CONFIG`:

- **whatsapp / telefono / direccion / ciudad**: datos reales del salón.
- **instagram / instagramTexto**: cuenta de Instagram.
- **portada**: foto grande de la portada (vacío = líneas animadas).
- **fotos**: fotos del carrusel (ponlas en `img/` y escribe la ruta en `src`).
- **horario**: horario por día de la semana.

Los servicios y precios se editan directamente en la lista `<ul class="menu">`.
