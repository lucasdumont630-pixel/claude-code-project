# Blackstar · Barbería & Tattoo (Alicante)

Web de una sola página: `index.html` (sin dependencias, abre directamente en el navegador).

- **Modo Barber / Tattoo**: el interruptor de la cabecera cambia toda la identidad de la web.
- **Fade Lab**: el cliente diseña su degradado (peine, altura, largo) y copia la receta para su cita en Booksy.
- **Galería de cortes**: pon tus fotos en `img/cortes/` y enlázalas en el array `CORTES` de `index.html`.
- **Servicios y horario**: edita `SERVICIOS` y `HORARIO` en el mismo bloque "DATOS EDITABLES".
