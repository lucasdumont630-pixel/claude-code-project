# YZEE Male Club · Web

Web de una sola página para **YZEE Male Club | Hair & Beauty Studio** (C/ Calderón de la Barca, 12, 03004 Alicante).

- `index.html`: la web completa (HTML + CSS + JS, sin dependencias de build).
- `img/`: fotos del estudio, del equipo y de trabajos, sacadas del perfil de Booksy.

Abre `index.html` en el navegador o súbelo a cualquier hosting estático (Vercel, Netlify, GitHub Pages).
Las reservas enlazan al perfil de Booksy.
